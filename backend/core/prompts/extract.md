# 請求書画像からの直接構造化

この画像は日本の請求書の 1 ページです。
印字されている内容だけを根拠に、指定されたスキーマへ直接構造化してください。

## 取引先の見分け方

- supplier_name は **請求書を発行した側**の会社名です。多くは右上に住所・電話番号・登録番号と
  一緒に印字されています。
- 「御中」が付いている会社は**請求先**であり、supplier_name ではありません。取り違えないこと。
- registration_number は `登録番号: T` で始まる 13 桁の番号です。印字されていれば必ず読み取る。

## 守ること

- null にする前に、画像全体(ヘッダー・フッター・欄外・表の外側を含む)を必ず見直す。
  一度で見当たらなくても、別の表記や別の場所に同じ値がないか確認してから判断する。
  null は「探して見つからなかった」結果であり、最初からの既定値にしない。
- 金額や番号の桁は一文字ずつ確認する。似た文字(0/O、1/7、8/6 など)や桁数の誤りがないか、
  画像の印字と突き合わせて再確認する。
- 画像に印字されていない値は null にする。計算して補わない。推測しない。スキーマの例をそのまま
  写さない。
- 金額は日本円の整数にする。カンマ、¥、円 は取り除く。△ または ▲ が付く値は負の数にする。
- 日付は YYYY-MM-DD にする。令和 N 年は西暦 N+2018 年に直す。
- 明細行は印字されている行だけを、印字されている順に読む。列をずらさない。数量・単位・単価が
  空欄の行は、その項目を null にしたまま金額だけ読む。
- 明細行には 小計・消費税・合計 の行を含めない。それらは専用の項目に入れる。
- 消費税の行が税率ごとに分かれている場合は、tax_summaries に税率ごとに書き出す。
  「（対象 103,200）」のような対象金額も読み取る。
- printed_total は 御請求金額 などの枠に印字された税込金額、total_amount は合計欄の金額。
  両方が印字されていれば、別々の値として読む。
- 手書きの書き込みや欄外の注記は notes_excluded にそのまま写し、金額や日付の項目には入れない。
