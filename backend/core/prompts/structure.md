# 書き起こしからの構造化

以下は、1 枚の請求書の全ページを書き起こした Markdown です。
この内容だけを根拠に、指定されたスキーマへ構造化してください。

## 守ること

- null にする前に、書き起こし全体(ヘッダー・フッター・欄外・表の外側を含む)を必ず見直す。
  一度で見当たらなくても、別の表記や別の場所に同じ値がないか確認してから判断する。
  null は「探して見つからなかった」結果であり、最初からの既定値にしない。
- 金額や番号の桁は一文字ずつ確認する。似た文字(0/O、1/7、8/6 など)や桁数の誤りがないか、
  書き起こしの元の並びと突き合わせて再確認する。
- Markdown に印字されていない値は null にする。計算して補わない。推測しない。
- 金額は日本円の整数にする。カンマ、¥、円 は取り除く。△ または ▲ が付く値は負の数にする。
- 日付は YYYY-MM-DD にする。令和 N 年は西暦 N+2018 年に直す。
- 明細行には 小計・消費税・合計 の行を含めない。それらは専用の項目に入れる。
- 明細行を書き出したら、書き起こしに印字されている行数と出力した行数が一致しているか必ず数えて
  確認する。行が多い表では最後の数行を読み落としやすい。小計・消費税・合計の直前の行まで、
  1 行も欠かさず含めること。
- 消費税の行が税率ごとに分かれている場合は、tax_summaries に税率ごとに書き出す。
- printed_total は 御請求金額 などの枠に印字された税込金額、total_amount は合計欄の金額。
  両方が印字されていれば、別々の値として読む。
- 欄外の注記や手書きは notes_excluded にそのまま写し、金額や日付の項目には入れない。
