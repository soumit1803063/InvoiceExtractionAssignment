# 請求書ページの書き起こし

この画像は日本の請求書の 1 ページです。
印字されている内容を、そのまま Markdown に書き起こしてください。

## 守ること

- 印字されている文字と数字だけを書く。読み取れない箇所は `?` と書き、推測しない。
- 明細は Markdown の表として書く。列は印字されている順のまま、列をずらさない。
- 空欄のセルは空欄のまま残す。0 や仮の値で埋めない。
- 金額のカンマ、通貨記号、△ や ▲ の符号は印字されているとおりに写す。
- 小計・消費税・合計 の行も、明細表と同じ表の中に、印字されている行として残す。
- 消費税の行に「（対象 103,200）」のような対象金額が印字されていれば、それも省かずに写す。
- 登録番号、請求書番号、発行日、お支払期日、御請求金額 は本文中にそのまま書く。
- 手書きの書き込みや欄外の注記は、末尾に `## 欄外` として分けて書く。
- 説明、要約、感想は書かない。書き起こしだけを返す。
