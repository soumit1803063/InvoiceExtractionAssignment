# 日本の請求書の読み取り規則

## 項目名

| 表記 | 意味 |
| --- | --- |
| 請求書 / 御請求書 | 文書の種別 |
| 請求書番号 | 請求書の番号 |
| 発行日 | 発行日 |
| お支払期日 | 支払期日 |
| 品名・摘要 | 明細行の品名 |
| 数量 | 明細行の数量 |
| 単位 | 明細行の単位 |
| 単価 | 明細行の単価 |
| 金額 | 明細行の金額 |
| 小計 | 税抜の合計 |
| 消費税 | 消費税額 |
| 税率 | 明細行ごとの税率 |
| 合計 / 御請求金額 | 税込の合計 |
| 登録番号 | 適格請求書発行事業者の登録番号 |
| 御中 | 宛先(受取側)を示す敬称 |
| お振込先 | 振込口座 |

## 取り違えやすい点

- 「御中」が付いている会社名は**受取側**であり、請求元ではない。請求元は「御中」が付かない側の会社名で、住所・TEL・登録番号と同じ欄に書かれている。この二つを入れ替えないこと。
- 「登録番号」は T で始まる 13 桁の数字。請求書番号や電話番号と混同しない。

## 記号と数値

- `△` と `▲` は**負の数**を表す。`△30,000` は `-30000` として読む。値引き行でよく使われる。
- 全角数字は半角(ASCII)に直す。`１２０` は `120`。
- 金額はカンマ・`¥`・`円` を取り除いた整数にする。小数は使わない。

## 日付

- 出力は西暦の `YYYY-MM-DD`。
- 令和は `令和N年M月D日` の形で書かれる。西暦 = N + 2018。令和1年は2019年、令和8年は2026年。
- `2026年1月7日` は `2026-01-07`、`2026/01/18` は `2026-01-18` に正規化する。

## 単位

- `単位` は明細行ごとに必須。例: 個 式 箱 本 袋 件 時間 セット。
- 印字が無い場合は必ず null にする。**推測して埋めない。** 空欄のままなら人が確認して入力する。

## 消費税

- 税は**税率ではなく税コード**で扱う。`T10` は 10%、`T08` は 8%。
- 税額は税コードごとに、そのコードの小計に対して計算し、**切り捨て**る。
- 明細行に `税率` 列が無く、請求書全体が単一税率であれば、その税率を全行に適用する。
- 「小計」「消費税」「合計」の行は明細行ではない。合計欄として読む。
